fungsi / function:
sekumpulan blok kode yang ada di dalam program yang nantinya bisa di panggil beberapa kali

Keuntungan menggunakan function / fungsi:
1. Mengurangi kode yang berulang.
2. Program lebih terstruktur.
3. Kode lebih mudah dibaca.
4. Kode lebih mudah diperbaiki.
5. Function dapat digunakan berkali-kali.
6. Program besar dapat dibagi menjadi beberapa bagian kecil.
